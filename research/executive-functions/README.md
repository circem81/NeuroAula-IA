# Funciones ejecutivas

Área de investigación sobre procesos relevantes para el aprendizaje, como memoria de trabajo, control inhibitorio, flexibilidad cognitiva, planificación, monitorización y autorregulación.

El objetivo es traducir evidencia científica a variables educativas observables, tareas de apoyo y estrategias de intervención pedagógica, evitando inferencias clínicas no justificadas.

Cualquier indicador utilizado en NeuroAula AI debe interpretarse junto con el contexto, la evolución temporal y la supervisión del profesorado u otros profesionales responsables.
