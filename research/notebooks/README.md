# Notebooks de investigación

Espacio para análisis reproducibles, pruebas de concepto y experimentos de ciencia de datos vinculados a la línea de neurociencia y aprendizaje de NeuroAula AI.

Buenas prácticas previstas:

- documentar fuente, licencia y versión de cada dataset;
- separar datos crudos, datos derivados y resultados;
- fijar semillas y dependencias cuando sea relevante;
- evitar incluir datos personales reales del alumnado;
- describir claramente qué es exploratorio y qué está validado;
- no convertir resultados experimentales en diagnósticos clínicos.
