# Modelos cognitivos

Espacio para formalizar modelos que representen el estado de aprendizaje sin reducirlo a una única nota o etiqueta.

Un modelo futuro podría integrar dimensiones como razonamiento, memoria de trabajo, velocidad de procesamiento, atención, inhibición, flexibilidad, conocimiento previo, estrategia, metacognición y progreso longitudinal.

Estos modelos deben ser interpretables, revisables por profesionales y limitarse a finalidades educativas o de investigación. No deben producir diagnósticos clínicos automatizados.
