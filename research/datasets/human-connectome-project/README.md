# Human Connectome Project (HCP)

Área de referencia para estudiar metodologías de conectividad cerebral, representación multidimensional y relaciones entre medidas cognitivas.

## Posibles usos metodológicos

- Comprender cómo se integran múltiples variables cognitivas en un mismo modelo.
- Explorar técnicas de reducción de dimensionalidad y representaciones latentes.
- Inspirar el diseño del gemelo de aprendizaje como estado longitudinal multidimensional.

## Límite de uso

NeuroAula AI no pretende inferir estados cerebrales del alumnado ni trasladar resultados de neuroimagen a decisiones educativas individuales sin evidencia específica y validación independiente.
