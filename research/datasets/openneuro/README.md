# OpenNeuro

Área destinada a documentar y reproducir análisis con datasets públicos de neuroimagen, EEG y otros formatos disponibles en OpenNeuro.

## Posibles usos metodológicos

- Práctica de pipelines reproducibles de neurociencia computacional.
- Extracción y análisis de características.
- Validación de notebooks de investigación.
- Estudio de tareas relacionadas con memoria de trabajo, atención o inhibición cuando existan datasets adecuados.

## Precaución

Los resultados obtenidos en datasets de investigación no deben presentarse como evidencia suficiente para inferir el funcionamiento cerebral o realizar diagnóstico sobre alumnado de NeuroAula AI.
