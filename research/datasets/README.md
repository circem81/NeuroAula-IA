# Datasets de investigación

Catálogo de conjuntos de datos que pueden servir para estudiar metodologías de neurociencia computacional y ciencia de datos aplicables, de forma indirecta y prudente, al diseño de NeuroAula AI.

Los datos externos no deben mezclarse con datos personales reales del alumnado. Cada dataset debe documentar licencia, condiciones de acceso, población, variables disponibles, sesgos conocidos y límites de generalización.

Actualmente se contemplan:

- Healthy Brain Network (HBN)
- Human Connectome Project (HCP)
- OpenNeuro
